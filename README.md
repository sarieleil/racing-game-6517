# 🏎️ PROFESSIONAL JUNGLE KART RACING

## Mario Kart Style 3D Racing Game

### Features:
- Professional 3D graphics
- Real racing controls
- Track with solid barriers  
- Beautiful cartoon karts
- Multiplayer racing
- Mobile + Desktop support

### Controls:
**Desktop:**
- ⬆️ W / Arrow Up = GAS (Accelerate)
- ⬇️ S / Arrow Down = BRAKE/REVERSE
- ⬅️ A / Arrow Left = STEER LEFT
- ➡️ D / Arrow Right = STEER RIGHT
- SHIFT = DRIFT

**Mobile:**
- Touch buttons on screen

### Deploy to Render:
```
npm install
npm start
```
